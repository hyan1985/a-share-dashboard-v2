# A股看板

两个页面，解决两个问题：**今天市场什么状态**、**哪些红利股到了该买的位置**。

本地跑、不需要服务器：

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export TUSHARE_TOKEN=你的token
make fetch && make run && make view
```

## 一、总览

不预测涨跌，只描述状态。

| 模块 | 内容 |
|---|---|
| **情绪冰点** | 股吧文本情绪（约 1200 条帖子）+ 市场宽度 + 赚钱效应 + 连板高度，合成 0~100 分 |
| **大跌风险** | 结构拥挤 + 破位风险，出 0~100 分和「偏低/中性/偏高」 |
| **关键点位** | 突破位 / 承接位 / 破位位，按均线、摆动高低点、整数关口、未回补缺口加权 |
| **红利估值** | 高股息股中位股息率的历史分位 |
| **量能位置** | 成交额相对近一年/近三年/20 日均值的位置 |

情绪分的口径（`src/kit/text_sentiment.py` + `config/lexicon.json`）：

- 分词后按多头/空头词典打分，含否定词处理
- **中性帖不计入分母**——否则大量纯信息帖会把分数稀释到 0
- 反讽用正则识别：`牛市+哈哈`、`感谢主力`、`牛回速归`、`抄底被埋` 等

## 二、红利股 · 渣男手册

按 [《红利股投资—渣男手册法》](https://zhuanlan.zhihu.com/p/2005229832628348776) 的思路实现：**先用财报排雷，再用均线定位**。

### 硬门槛（全部满足才进候选）

| 指标 | 要求 | 理由 |
|---|---|---|
| PE(TTM) | < 20 | > 25 不考虑 |
| 股息率 | > 3% | > 5% 优秀 |
| 毛利率 | > 30% | 证明有定价权 |
| ROE | > 15% | 连续多年 |
| 经营现金流 | > 净利润 | 利润是真金白银 |
| 资产负债率 | < 65% | 非金融企业 |
| 派息率 | 30% ~ 100% | > 100% 在吃老本 |
| 收现比 | > 1.0 | 销售商品收到的现金 ÷ 营业收入 |

### 均线定位

以 **120 日均线**为锚：

```
价格 ≤ MA120 × 0.88   →  买入区
价格 ≥ MA120 × 1.12   →  卖出区
之间                  →  观望
```

分红复投提示：价格低于 **MA60** 时标注 `reinvest_ok`。

## 漏斗

每次运行会输出筛选漏斗，看是哪一步卡住的：

```
5570 只全市场
 → 928   PE < 20
 → 458   股息率 > 3%
 → 247   毛利率 > 30%
 → 81    ROE > 15%
 → 77    负债率 < 65%
 → 52    经营现金流 > 净利润
 → 52    过全部门槛
```

## 已知限制

1. **收现比需要 `cashflow` 和 `income` 表**。缺表时标注「未校验」，不默认通过。
2. **分红数据（连续年数、派息率）需要 `dividend` 表**，逐股拉取成本高。缺表时同样标注未校验。
3. **价格低于 MA120 一半的会被剔除**（`ratio < 0.5`），多半是复权或上市初期数据问题，不是真的便宜。
4. **不做买卖建议**。买入区只是「相对自己的半年线便宜」，不代表会涨。

## 曾经有、后来删掉的分区

擒龙猎手、捡烟蒂、长期吃息打分版、横盘突破、财报季、定投仪表盘。

删掉的原因不是代码不好，是**回测下来没有稳定超额**：

```
擒龙猎手   5/10/20 日超额 -0.48% / -1.58% / -2.68%
横盘突破   -0.65% / -0.76% / -0.90%
捡烟蒂     最脆弱，top5 和 0.3% 成本两个假设下都亏
```
