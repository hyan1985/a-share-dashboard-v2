# A股看板

两个页面，解决两个问题：**今天市场什么状态**、**哪些红利股到了该买的位置**。

本地跑、不需要服务器：

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export TUSHARE_TOKEN=你的token
make fetch && make run && make view
```

## 一、总览

不预测涨跌，只描述状态。

| 模块 | 内容 |
|---|---|
| **情绪冰点** | 股吧文本情绪（约 1200 条帖子）+ 市场宽度 + 赚钱效应 + 连板高度，合成 0~100 分 |
| **大跌风险** | 结构拥挤 + 破位风险，出 0~100 分和「偏低/中性/偏高」 |
| **关键点位** | 突破位 / 承接位 / 破位位，按均线、摆动高低点、整数关口、未回补缺口加权 |
| **红利估值** | 高股息股中位股息率的历史分位 |
| **量能位置** | 成交额相对近一年/近三年/20 日均值的位置 |

情绪分的口径（`src/kit/text_sentiment.py` + `config/lexicon.json`）：

- 分词后按多头/空头词典打分，含否定词处理
- **中性帖不计入分母**——否则大量纯信息帖会把分数稀释到 0
- 反讽用正则识别：`牛市+哈哈`、`感谢主力`、`牛回速归`、`抄底被埋` 等

## 二、红利股 · 渣男手册

按 [《红利股投资—渣男手册法》](https://zhuanlan.zhihu.com/p/2005229832628348776) 的思路实现：**先用财报排雷，再用均线定位**。

### 硬门槛（全部满足才进候选）

| 指标 | 要求 | 理由 |
|---|---|---|
| PE(TTM) | < 20 | > 25 不考虑 |
| 股息率 | > 3% | > 5% 优秀 |
| 毛利率 | > 30% | 证明有定价权 |
| ROE | > 15% | 连续多年 |
| 经营现金流 | > 净利润 | 利润是真金白银 |
| 资产负债率 | < 65% | 非金融企业 |
| 派息率 | 30% ~ 100% | > 100% 在吃老本 |
| 收现比 | > 1.0 | 销售商品收到的现金 ÷ 营业收入 |

### 均线定位

以 **120 日均线**为锚：

```
价格 ≤ MA120 × 0.88   →  买入区
价格 ≥ MA120 × 1.12   →  卖出区
之间                  →  观望
```

分红复投提示：价格低于 **MA60** 时标注 `reinvest_ok`。

## 漏斗

每次运行会输出筛选漏斗，看是哪一步卡住的：

```
5570 只全市场

 → 458   股息率 > 3%
 → 247   毛利率 > 30%
 → 81    ROE > 15%
 → 77    负债率 < 65%
 → 52    经营现金流 > 净利润
 → 52    过全部门槛
```

## 已知限制

1. **收现比需要 `cashflow` 和 `income` 表**。缺表时标注「未校验」，不默认通过。
2. **分红数据（连续年数、派息率）需要 `dividend` 表**，逐股拉取成本高。缺表时同样标注未校验。
3. **价格低于 MA120 一半的会被剔除**（`ratio < 0.5`），多半是复权或上市初期数据问题，不是真的便宜。
4. **不做买卖建议**。买入区只是「相对自己的半年线便宜」，不代表会涨。

## 银行专区的回测结论（重要）

这一档做过三次回测，脚本都在 `tools/` 下，结论有正有负，**建议看完再决定信不信**。

数据：2017-06 ~ 2026-03，106 个月 × 42 只银行，预测未来收益，用 rank IC。

### 一、因子有没有预测力

| 因子 | IC 5日 | IC 20日 | IC 60日 | IC 120日 |
|---|---:|---:|---:|---:|
| 双估值便宜度 | −0.003 | 0.027 | 0.064 | 0.088 (t 4.3) |
| 一年位置 | 0.076 | 0.123 | 0.189 | 0.235 (t 8.6) |
| 近 3 月涨幅 | 0.003 | 0.026 | 0.066 | 0.104 (t 3.4) |

三个因子在 60/120 日都显著，符号全为正。**20 日窗口下它们几乎无效**——
最早只用 20 日回测，差点误判成「没有信号」。

### 二、盈亏比的目标价该用哪个

| 目标价定义 | IC 20日 | IC 60日 | IC 120日 |
|---|---:|---:|---:|
| 近一年高点 | 0.079 | 0.081 | **0.104** |
| MA120 × 1.12 | 0.079 | 0.077 | 0.082 |
| 双估值 × 1.3 | −0.075 | −0.085 | **−0.091** |

用双估值当目标价会**反向**：买点随 EPS/DPS 抬高，说明基本面在变好、
市场早已反映，算出来的「上行空间」大，实际是买在兑现之后。

### 三、但盈亏比不能当交易门槛

按盈亏比分组看未来 120 日：

| 盈亏比 | 样本 | 均值 | 胜率 |
|---|---:|---:|---:|
| < 0 | 2012 | 1.19% | 51.2% |
| **0 ~ 0.5** | 432 | **6.13%** | **65.5%** |
| 0.5 ~ 1.0 | 264 | 4.05% | 59.8% |
| 1.0 ~ 1.5 | 168 | 4.60% | 58.9% |
| > 1.5 | 946 | 2.72% | 54.4% |

**不单调**，最好的区间是 0~0.5 而不是 >1。

盈亏比 >1 的标的，120 日胜率 55.1%，全样本 54.6%——**只高 0.5 个百分点**，
扣掉交易成本就没了。分年度胜率在 35%（2019）到 90%（2024）之间乱跳。

**IC 0.104 统计显著，但换算成胜率不可交易。这是统计显著 ≠ 能赚钱的例子。**

### 所以这一档的定位

| 步骤 | 能干什么 | 不能干什么 |
|---|---|---|
| 硬门槛（PE/股息/ROE/分红年数） | 筛掉不合格的 | 不预测涨跌 |
| 基本面门槛（双估值溢价 ≤30%） | 排除市场价远超基本面支撑的 | 不作为买入理由 |
| 盈亏比 | **只是展示** | **不作为排序或门槛** |

**排序用的是股息率**——那是确定会发生的现金流，不是预测。
